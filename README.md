# 🚀 RealMify

## Plataforma de Estudos Gamificada

O RealMify é uma aplicação web desenvolvida para transformar a rotina de estudos em uma experiência mais organizada e interativa através da gamificação.

A plataforma permite que estudantes acompanhem seu progresso, organizem seus estudos e evoluam utilizando elementos inspirados em jogos, como XP, níveis e recompensas.

## ✨ Funcionalidades

- Cadastro e autenticação de usuários
- Perfil personalizado
- Biblioteca de conteúdos
- Lista de tarefas
- Temporizador de estudos
- Sistema de XP
- Sistema de níveis
- Recompensas
- Mapa de evolução
